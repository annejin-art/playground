## 底层逻辑：先认识自己，再谈方向
斯斯不先问“你想做什么”，而是先盘“你过去靠什么赚到钱”。方向不是想出来的，是从盘点里长出来的。

## 六个步骤
1. **盘筹码：谁真金白银为你买过单？** 摊开过去，找出真实被市场付费验证过的能力，不是简历上的头衔。
   - 例：连麦者2过去两次成功，都是“搞定一个不缺钱、信任她的老板，对方出钱出资源，她做经营管理”。她要复制的是这个模式，不是换行业。
2. **识别赚钱的“模式”（2B / 2C / 2老板 / 2投资人）。** 问：钱从哪一层来？我的成功路径是什么？
   - 成功模式换了打法（如突然投100份简历、从下往上打），就是模型错了。
3. **手里有什么 × 客户要什么。** 两个问题问到底，方向自己浮现。
   - 从流量思维(1.0：我有流量就能变现)切到客户思维(2.0：谁在给钱、他们下半年要什么，我站在需求延长线上设计生意)。
4. **分清重 / 轻。** 重 = 自己扛生产成本、团队，靠投入建门槛；轻 = 掌握客户和需求，做销售/中介/撮合。看自己对哪种投入会“痛心、犹豫”，犹豫的那边就别硬上。
   - 连麦者1：每次为内容投入都痛心（汽车越做越累、AI口播做不下去、财经合作没谈清）→ 走轻，去价值链客户端。
5. **长板 / 短板，以及“门槛是朋友还是敌人”。**
   - 门槛高是朋友，门槛低是敌人（人人都能做，竞争就残酷）。想省的那份力，往往是稀释竞争力的敌人。
   - 不要拿自己的短板去拼别人的长板（例：社交是短板，就别选要搭讪陌生人的街拍）。
6. **爱好 / 副业 / 欲望三分法。**
   - 爱好：不需要别人鼓励，能量高低都想做，做了就开心，考虑自己。
   - 副业：用来赚钱，考虑客户。
   - 欲望：想得到别人也想要的结果，必须付出代价（持续更新、克服心魔）。欲望高、付出低，交易就达不成；要么降欲望，要么加付出。
   - 判断办法：看是“迫不及待去做”，还是“要等能量高才做”。

## 谋局：从盘点到行动
- 不做线性努力（海投、多面试、多认识HR），要先问：我想要的老板在哪、他需要什么、谁是我身边的“超级节点”、我怎么创造认识的场合、释放什么信息。
- “A到B中间缺一块”，就搭跳板：朋友推荐、猎头、行业峰会、线下课/EMBA同学等。
- 从上往下设计：2C → 小B → 大B → 老板 → 投资人，内容要为最终想认识的那一层服务。

## 看清自己的元认知工具
- **元认知**：像旁观者一样看自己的思维方式和惯性。
- **拖延/混乱有收益**：反复拖着不动，说明它给了你好处（逃避、无限延长实现时间）。拿白纸写：拖延带给我什么？执行带给我什么？我要哪个？
- **混乱 = 低能量，清晰 = 高能量。** 看清是对自己负责。
- **提示词（节目原话大意）：** 让AI问你10个问题，出报告：我是什么样的人、想要什么生活、什么是爱好/副业/欲望、我的能力圈、长板短板、哪里竞争不过别人。
